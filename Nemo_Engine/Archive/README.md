The moves reuse the original Git blob objects. Preset bytes, settings, prompt ordering, and embedded regex scripts are unchanged. Previously archived versions and the `NemoSet` folder remain untouched.

The former [v11.5.1 README](./README-v11.5.1.md) is preserved byte-for-byte as historical documentation. Its text, version-specific claims, and some relative links reflect the old folder layout. The anniversary image it refers to remains in [the parent assets folder](../assets/).

The separate [Archived Prompts](../Archived%20Prompts/) folder is unchanged. Import a complete JSON to use a historical preset; the individual prompt documents are reference material, not replacement preset exports.
